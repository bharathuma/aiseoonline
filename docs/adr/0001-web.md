# ADR 0001: Astro and React

**Status:** Accepted; not implemented.

## Context

Most SEO utility pages need fast loading and indexable explanatory content. Forms, progress updates, reports, and chat require client-side interaction.

## Decision

Use Astro for public page rendering, with React components for interactive sections. TypeScript and Tailwind CSS will provide shared conventions and styles.

## Alternatives

A fully client-rendered React app would use more browser JavaScript for content-focused pages. Next.js offers integrated features that are not necessary at the initial scale.

## Consequences

The project will need clear boundaries between Astro pages and React islands, including shared types, hydration decisions, and accessible UI components.
