# Code of Conduct

AISEOOnline is intended to be a welcoming place for people to collaborate on useful software.

Be respectful, offer constructive feedback, and discuss technical decisions without personal attacks. Harassment, discrimination, threats, spam, and publishing private information are not acceptable.

This policy applies to repository issues, pull requests, reviews, and project discussions. Maintainers may remove inappropriate content or restrict participation.

For concerns about community conduct, use GitHub's reporting features or reach the repository owner through an available private contact method. Avoid posting sensitive reports publicly. Security issues are handled separately under [SECURITY.md](SECURITY.md).
